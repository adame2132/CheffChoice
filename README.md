# Chief Choice

## Description
**Chief Choice** is an online web application that allows users to create, view, and share recipes with a community of fellow cooking enthusiasts. The platform features user authentication, authorization, and session management, enabling users to securely log in and access personalized content. Users can view public recipes shared by others as well as manage their own recipes—editing descriptions and ingredients as needed. Authorization ensures that only the original creator of a recipe has the ability to modify it, promoting both collaboration and privacy. **Chief Choice** offers a simple and interactive way to explore and share culinary creations.
